# MockBuddy

## Что это
MockBuddy — маркетплейс подготовки к собеседованиям для Product Manager-ов на рынке СНГ. Объединяет AI-тренажёр и живых интервьюеров из топовых компаний (Яндекс, Kaspi, Ozon, Тинькофф, Google).

## Целевая аудитория
- Джуны и переключенцы в PM (20–28 лет)
- Мидл PM-ы в поиске роста (25–35 лет)
- Сеньор PM-ы целящиеся в FAANG (28–40 лет)
- Рынок: Россия, Казахстан, Кыргызстан, Узбекистан, Беларусь

## Стек
- Frontend: Next.js 15, TypeScript, Tailwind CSS v4, App Router
- Auth: Clerk (@clerk/nextjs)
- БД: Supabase (PostgreSQL)
- AI: OpenAI GPT-4o (интервьюер, анализ, резюме)
- Платежи: CloudPayments (позже)
- Деплой: Vercel
- Язык интерфейса: русский (с возможностью английского позже)

## Структура проекта
/app — страницы (App Router)
/app/(landing) — лендинг
/app/(dashboard) — личный кабинет
/app/(interview) — AI-интервью
/app/(results) — результаты и фидбек
/components — переиспользуемые компоненты
/components/ui — базовые UI элементы
/components/layout — шапка, подвал, навигация
/components/interview — компоненты интервью
/lib — утилиты и конфиги
/lib/ai — промпты и логика AI интервьюера
/lib/supabase — клиент и запросы к БД
/types — TypeScript типы
/public — статика

## Текущая фаза: MVP
Фокус на:
1. Landing page с waitlist
2. AI mock-интервью (текстовый чат)
3. Анализ вакансий
4. Фидбек и скоринг ответов
5. Генерация резюме

## Правила разработки
- Весь UI на русском языке
- Тёмная тема по умолчанию
- Mobile-first дизайн
- Код комментировать на английском
- Компоненты — функциональные (React hooks)
- Никаких any в TypeScript — всегда типизировать
- Каждая страница — отдельная папка в /app
- Переменные окружения в .env.local, примеры в .env.example

## Команды
- `npm run dev` — запуск dev-сервера
- `npm run build` — сборка
- `npm run lint` — линтинг
